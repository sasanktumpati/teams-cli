teams {version}: local, append-only SQLite archive of macOS Microsoft Teams chats.

Conventions
  --json on read commands matches the HTTP API shape.
  Chats (--chat, messages CHAT) & people (--from) accept a name fragment, email, or id ("otherMatches"/"senders" flag ambiguity).
  Times (--since/--until): 30m 12h 7d 2w today yesterday 2026-11-01 2026-11-01T14:00 (local); --since all clears default 7d windows.
  --limit 0 = unlimited; "matched" is total count, "truncated": true means more exist.
  Search: prefix words, "exact phrase", OR, NOT, -exclude / -"phrase"; --relevance weights subject > body.
  Exit codes: 0 ok, 1 runtime/archive/health error, 2 bad input. Errors go to stderr.
  HTTP API (127.0.0.1:{port}, loopback Host only, no Origin):
    GET /health (open); all /v1/* require `Authorization: Bearer <token>` (`teams token` or `teams token create`).
    GET /v1/<cmd> (camelCase flags): status, chats(query member kind), messages(chat|around context sender thread includeHistory),
    search(query includeHistory countOnly hasAttachments sender chat sort=relevance), attachments, people, person(person),
    changes(what=edited|deleted), records(source key allVersions), inbox, mentions(chat unreadOnly), calls(person missedOnly),
    meetings(query), saved(includeUnsaved), pinned(chat); since/until/limit/includeEvents as in CLI. POST /v1/sync.
    Errors: {error: {code, message}} (401 unauthorized + WWW-Authenticate: Bearer, 409 sync_busy/empty_archive, 503 migrating).

JSON shapes
  message     {id, chatId, chatName?, threadId, isReply, time, sender, senderId, kind, text, subject,
               attachments: [{kind: file|image|link, name, url}], reactions: [{emoji, count, users}],
               edited, editedAt, deleted, deletedAt, deletedBy, history?: [{text, editedAt, capturedAt}]}
  attachment  {kind, name, type, url, time, sender, chatName, chatId, messageId, messageDeleted, messageText, localPath?}
  fetch       {path, sizeBytes, contentType, url, name, kind, source: download|onedrive} (CLI only)
  send        [RESTRICTED] CLI only; dry-run unless --yes and TEAMS_CLI_ENABLE_SEND=1 (optional TEAMS_CLI_SEND_ALLOWLIST)
  messages    {chat, messages, matched, truncated, otherMatches, aroundMessageId?, hasBefore?, hasAfter?}
  search      {query, chat, senders, results?: [message + snippet, chatName, matchedInHistory?], matched, truncated?, countOnly?}
  chats       {chats: [{id, name, kind, messageCount, lastActivity}], total, memberMatches?}
  person      {person: {id, name, email, jobTitle, department, messagesInArchive, firstContact, lastContact},
               sharedChats, totalSharedChats, recentFiles, totalAttachments, otherMatches}
  inbox       {me, since, unreadChats, awaitingReply, mentions, unreadActivities, counts}
  mentions    {me, chat, mentions: [{messageId, chatId, chatName, time, sender, text, isRead}], matched, truncated}
  calls       {calls: [{id, time, endTime, durationSeconds, direction, callType, state, participants, chatName}]}
  meetings    {meetings: [{id, subject, start, end, organizer, myResponse, joinUrl, chatId, attendees}]}
  saved       {saved: [{messageId, chatId, chatName, savedAt, time, sender, text, deleted, unsaved}]}
  pinned      {chat, pinned: [{messageId, chatId, chatName, time, sender, subject, text, source}]}
  verify      {ok, archive|target, checks, backups?, errors}
  restore     {restoredFrom, archive, safetyBackup}
  doctor      {ok, version, schemaVersion, checks: [{name, ok, summary, hint?}]}
  migrations  {currentVersion, targetVersion, applied: [{version, name, appliedAt, appVersion, durationMs}], pending}
